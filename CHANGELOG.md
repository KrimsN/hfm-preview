# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [SemVer](https://semver.org/lang/ru/).

## [0.1.0] — 2026-10-09

Первая публичная версия.

### Добавлено

- Язык HFM для файлов `*.habr.md`: подсветка синтаксиса, outline по заголовкам.
- Превью статьи в стиле Хабра: заголовки, списки, цитаты, таблицы, спойлеры, формулы,
  вставки видео и соцсетей, блок «персона», локальные картинки.
- Подсветка кода по списку языков Хабра.
- Светлая и тёмная тема превью, переключение из контекстного меню.
- Синхронизация прокрутки редактора и превью, восстановление превью после перезапуска.
- Диагностика конструкций, которые Хабр не поддерживает или искажает, с быстрыми исправлениями.
- Подсказки по типографике Хабра: кавычки, тире, пробелы в числах, даты, инициалы.
